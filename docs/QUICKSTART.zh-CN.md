# 预测结果复核工具：使用指南

现在包含三个可操作入口：用月度数据训练回归候选、复核已有预测、对账金融数值结果。都支持本地 CSV／Excel 字段选择和离线证据导出。

## 打开

Mac 用户首次安装好 Python 3.10 或更新版本后，双击仓库中的 `start.command`。首次安装需要下载依赖，以后可以离线使用。启动后浏览器会打开本地工具；保持启动窗口运行，结束时关闭它即可。更新工具后，需要重新安装才能使用新版本。

第一次可以点击右上角 **Explore an example**。示例有 12 个预期月份，两份预测分别缺少不同月份，共同样本只有 7 期。它展示了为什么“自己的误差更低”不一定意味着“在相同样本上更好”。所有示例数字均为新造。

## 用月度数据训练候选

1. 顶部选择 **Training experiments**，导入自己的 CSV／Excel，选择工作表、表头行和月度日期／实际值列。
2. 添加 1—5 个原始特征列，声明每个特征的 lag（滞后月数）和 release delay（公布延迟）。工具会执行滞后，不要提前把原列平移。滞后必须至少等于预测期限加公布延迟。
3. 指定开发期结束月、开发划分数、每段验证月数和最少训练行数，点击准备开发结果。5 个特征会得到全部 15 个单／双因子候选和两个基线；失败候选也保留。
4. 查看同一组开发月份上的指标、每折训练范围、系数与失败原因。开发期 MAE 决定预选候选；不是按留出期挑选。
5. 固定开发选择后，明确点击揭示留出期。导出完整训练证据，或把选定候选和一个基线传入 **Forecast review**。传入后仍需检查覆盖并亲自接受共同样本。

月份必须唯一、连续；空特征会使相应滞后月份从所有模型的共同样本中排除。缺实际值、非法数值、公式或不连续日期会拒绝本次实验。目标变换仅记录声明，实际值按输入的尺度计算。示例使用新造的 180 个月数据、5 个特征及 24 个月留出期。

## 复核已有预测文件

1. 准备一份实际值表和 1—5 份候选预测表，可另外提供一份基线预测。支持 CSV 和只含固化值的 Excel。
2. 在 **Inputs & definition** 填目标、单位、预测期限、变换方式和完整预期期间。例如月度收入、USD、1 期、none、2024-01 至 2024-12。
3. 用 **Choose file** 选择文件。Excel 先选工作表和表头行，再指定 **Target period** 与实际值/预测值列。各文件列名和顺序可以不同。日期必须表示预测对应的目标期；工具不会按预测期限自动平移日期。
4. 确认每份文件下方 **Definition & source note** 的声明。确实一致时可用 **Use this definition for all files**；不能用这个按钮掩盖实际单位或目标不同。
5. 点击 **Check coverage**，检查缺失、重复、无效值及超出范围的记录。复核排除原因后，明确勾选接受共同样本。
6. 在 **Review & export** 看共同样本上的 MAE、RMSE、平均有符号误差，以及趋势和逐行证据。误差越小只说明当前样本上的误差更小。缺口仍限制结论。
7. 为候选选择人工意见并写理由，点击 **Download review ZIP**。解压后打开 `report.html`；下一位复核人还能用 CSV/JSON 复算并核对文件指纹。

如果文件包含多条序列，在每份文件中选择实体 ID 列，并在预期范围中逐行列出完整 ID。前导零和空格有含义，ID 应保存为文本。

修改输入、字段映射、来源声明或样本选择后，旧意见需要重新确认。准备下载时会暂时锁定意见编辑。原始文件不会被修改；导出含所选字段的值，分享时应按原文件的敏感程度处理。

## 对账金融数值结果

1. 选择 **Financial reconciliation**，导入参考侧与待比较侧文件，选择 Excel 工作表和表头。
2. 映射记录 ID、日期、指标、风险类型、期限、币种、单位和金额。重复出现的日期／单位等可以明确填成固定声明；ID 应为文本，保留前导零。
3. 设置绝对容差和相对容差。相对容差是比例，`0.001` 表示千分之一。通过条件为：绝对差异 ≤ 绝对容差 + 相对容差 × 参考侧绝对值。
4. 只有明确勾选数值可以相加，才计算同日期／指标／风险类型／期限／币种／单位的分组。可再导入每侧上报总额，与该侧原始行独立对账。
5. 分别检查逐项、分组和上报总额的待处理提示。正负差异抵消不能让问题行通过。即使逐项全通过，上报总额有错也会在顶部提示。
6. 搜索、翻页查看明细，为“接受差异”或“需补证据”写理由，导出 ZIP。人工意见始终保留为意见，不会把计算上的超差改成通过。修改文件、容差或声明会使旧意见失效。

对账的预期范围来自两侧记录的并集；两份文件都缺失的记录无法被发现。每个证据包都包含原始输入快照，应按输入资料的敏感程度保存。

## 使用边界

训练入口实现月度线性回归候选与两个基线；原预测审阅入口仍只评价提供的预测。工具不会计算 Excel 公式、换算单位、反变换、进行非线性保证金聚合或复刻专有定价引擎。自动检查不能证明来源声明属实、真人从未查看留出期或模型适合上线。第二位真人独立试用仍待完成。
