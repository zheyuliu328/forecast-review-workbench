# 预测结果复核工具：使用指南

这个工具接收你已有的预测结果，帮助你检查比较是否公平、误差在哪里，以及如何把理由交给下一位复核人。

## 打开

Mac 用户首次安装好 Python 3.10 或更新版本后，双击仓库中的 `start.command`。首次安装需要下载依赖，以后可以离线使用。启动后浏览器会打开本地工具；保持启动窗口运行，结束时关闭它即可。更新工具后，需要重新安装才能使用新版本。

第一次可以点击右上角 **Explore an example**。示例有 12 个预期月份，两份预测分别缺少不同月份，共同样本只有 7 期。它展示了为什么“自己的误差更低”不一定意味着“在相同样本上更好”。所有示例数字均为新造。

## 用自己的文件

1. 准备一份实际值表和 1—5 份候选预测表，可另外提供一份基线预测。支持 CSV 和只含固化值的 Excel。
2. 在 **Inputs & definition** 填目标、单位、预测期限、变换方式和完整预期期间。例如月度收入、USD、1 期、none、2024-01 至 2024-12。
3. 用 **Choose file** 选择文件。Excel 先选工作表和表头行，再指定 **Target period** 与实际值/预测值列。各文件列名和顺序可以不同。日期必须表示预测对应的目标期；工具不会按预测期限自动平移日期。
4. 确认每份文件下方 **Definition & source note** 的声明。确实一致时可用 **Use this definition for all files**；不能用这个按钮掩盖实际单位或目标不同。
5. 点击 **Check coverage**，检查缺失、重复、无效值及超出范围的记录。复核排除原因后，明确勾选接受共同样本。
6. 在 **Review & export** 看共同样本上的 MAE、RMSE、平均有符号误差，以及趋势和逐行证据。误差越小只说明当前样本上的误差更小。缺口仍限制结论。
7. 为候选选择人工意见并写理由，点击 **Download review ZIP**。解压后打开 `report.html`；下一位复核人还能用 CSV/JSON 复算并核对文件指纹。

如果文件包含多条序列，在每份文件中选择实体 ID 列，并在预期范围中逐行列出完整 ID。前导零和空格有含义，ID 应保存为文本。

修改输入、字段映射、来源声明或样本选择后，旧意见需要重新确认。准备下载时会暂时锁定意见编辑。原始文件不会被修改；导出含所选字段的值，分享时应按原文件的敏感程度处理。

## 首版边界

工具不会训练模型、生成基线、计算 Excel 公式、换算单位或反变换数据。仅凭预测文件，也不能证明训练没有泄漏或模型适合上线。自动化和独立复核已检查软件行为，真人独立试用尚未完成。
