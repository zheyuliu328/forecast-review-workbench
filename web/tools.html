How files are handled

Both web tools calculate in your browser, without registration. Forecast Review accepts up to 10 MiB, 10,000 rows, and 100 columns per file; Table Check accepts up to 8 MiB per file. The first run downloads the calculation runtime. Processing stops after two minutes.

Transferring an experiment to Forecast Review temporarily stores converted results in the current tab; they are removed after the destination page reads them. Refreshing loses current results, so download them promptly. Experiment and financial reconciliation ZIP files include complete source files; handle them with the same care as the originals.
