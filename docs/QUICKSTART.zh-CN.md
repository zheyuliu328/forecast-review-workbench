# 预测审阅：使用指南

[直接打开网页](https://forecast-review-zheyuliu.mystic-pear-2111.chatgpt.site) · [全部工具与状态](https://forecast-review-zheyuliu.mystic-pear-2111.chatgpt.site/tools.html)

无需安装或注册。先点右上角 **试用示例**，或者选择自己的 CSV／Excel。首次使用需要下载约 17 MB 的计算组件，文件始终在浏览器内处理。

## 比较已有预测

1. 选择一份实际值表和一份预测表，需要时再添加预测或基线。每份表至少有日期和数值两列；Excel 可选择工作表及表头行。
2. 核对日期和数值列，点击 **确认文件，下一步**。填写比较目标、单位及原本预期的完整期间。日期表示被预测的期间，工具不会自动平移。
3. 确认各文件含义一致后，点击 **我确认一致，应用到所有文件**；若实际不同，保留差异并检查来源。
4. 点击 **检查可比较的样本**。查看遗漏、重复与排除原因，再明确勾选接受共同样本。
5. 点击 **查看比较结果**。所有候选和基线使用相同记录计算 MAE、RMSE、偏差。需要时写下复核意见，再点 **下载完整复核包**。

示例预期有 12 个月，但共同样本只有 7 个月。候选 A 在自己的样本上看似更好，候选 B 在共同样本上的误差更低；另外 5 个月仍然缺失，不能据此给出完整期间的结论。

修改文件、映射、范围或单位后，原结果和样本确认失效，旧意见需要重新确认。多实体数据须提供完整实体 ID 清单；前导零和空格有含义。

## 用历史数据试建模型

1. 顶部选择 **用历史数据试建模型**，选择月度历史表和日期、实际值列。
2. 进入下一步，选 1—5 个原始特征列，填写滞后月数与公布延迟。不要先把原列平移；工具会执行滞后。
3. 指定开发期结束月与时间切分，点击 **运行开发期实验**。5 个特征会尝试 15 个单／双因子候选及两个基线，失败候选也保留。
4. 先审阅开发期，再确认并点击 **查看留出期结果**。开发期选定的候选不会按留出期得分重新挑选。
5. 下载实验包，或点击 **带入预测审阅**。带入后仍须亲自确认共同样本。

月份须连续且唯一。空特征会使有关月份从共同样本排除；缺实际值、公式及非法数值会阻止运行。当前仅提供月度线性回归候选；目标变换只是声明，不会自动逆变换。看过的留出期不能因为重新运行而重新变成未见数据。

## 核对逐笔结果和总额

1. 选择参考表与待比较表，确认记录 ID 和数值列。
2. 进入下一步，确认日期、指标、风险类型、期限、币种和单位，填写容差。
3. 点击 **开始对账**。只有明确勾选可加性后，才计算分组；需要时加入各侧上报总额。
4. 分别查看逐笔、分组与总额。正负差异抵消不会使超差记录通过；人工接受意见也不会改变计算状态。
5. 下载对账包，保留原值、来源、逐行差异及解释。

完整性范围来自两侧记录的并集，两份文件都缺失的记录无法被发现。相对容差是比例，0.001 表示千分之一。

## 文件与结果

- 每份文件最多 10 MiB、10,000 数据行、100 列；合计请求最多 40 MiB。处理超过两分钟自动停止，也可点击 **取消处理**。
- 关闭或刷新页面会丢失当前结果。实验转入预测审阅时，结果暂存在当前标签页的会话存储中，目标页读入后删除。
- 预测复核包包含所选字段值、逐行诊断和原文件哈希。实验及金融对账包包含完整原文件快照，包括未映射列和其他工作表，请按原文件的敏感程度保管。
- 解压下载包后，可直接打开 report.html；CSV／JSON 和哈希清单用于复算。
- 工具不计算 Excel 公式、不自动换汇或转换单位、不批准模型。真人独立使用及重复使用效果仍待验证。

## 可选：本机版

需要离线安装时，安装 Python 3.10 或更新版本，然后双击仓库里的 start.command。首次安装需下载依赖。更新源码后需重新安装，网页用户不需要此步骤。
