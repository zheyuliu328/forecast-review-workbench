# Working agreement

MODE=LOCAL_TOOL_BUILD. Build a usable local tool with an external-file workflow, then test the actual installed application.

Only public methods and independently invented fixtures belong in this repository. Do not copy private code, templates, customer data, identifiers, screenshots or history. The application reads user-selected files locally and never uploads them to an external service.

Keep engine calculations separate from transport, export and UI. Preserve every mapped input row in diagnostics. Common-sample metrics require explicit acceptance and compatible definitions. Do not describe software execution as model approval or infer training independence from prediction files.

The primary agent owns integration, packaging, documentation, exports, server, Git and final verification. Assigned worker ownership is non-overlapping. Independent reviewers remain read-only. All commits end with a NEXT: checkpoint. Existing files and outputs must not be overwritten by user-facing commands.
